# Service Information System

## Requirements
Local PHP server with PDO MySQL support and a MySQL database.
(XAMPP works. The `mbstring` PHP extension, enabled by default in XAMPP, is also used.)

## Database
Database name: `service_db`

Main table: `services`

| Column | Meaning |
| --- | --- |
| `id` | Generated by MySQL |
| `service_name` | Service Name |
| `category` | Category |
| `fee` | Fee |
| `available_slots` | Available Slots |

## Setup
1. Place the `service-system` folder in the local web server's document root (XAMPP: `htdocs`).
2. Import `database.sql` (phpMyAdmin > Import). It creates the database, the table, and 4 fictional records. Import it into a fresh setup only once.
3. Set local credentials and the database name in `config.php`.
4. Open the local URL below.

## Local URL
http://localhost/service-system/index.php

## Features
Create, list, view, edit, delete, and case-specific validation.

**Case rule:** All fields are required. Fee must be zero or more with at most two decimal places. Available slots must be a whole number of zero or more. Fees are shown with two decimal places.

## Files
| File | Role |
| --- | --- |
| `config.php` | Database settings and the PDO connection `$pdo` |
| `index.php` | Lists records with Add New, View, Edit, Delete links |
| `create.php` | Form, PHP validation, prepared INSERT |
| `view.php` | All fields of one record |
| `edit.php` | Filled form, validation, prepared UPDATE for one ID |
| `delete.php` | Confirmation page; deletes only on POST |
| `database.sql` | Database, table, sample records |
| `README.md` | This guide |

## Check the solution
1. Create Basic Haircut / Hair Care / 150.50 / 20 and confirm the fee shows 150.50.
2. Change the fee to 175.00 and slots to 0 and confirm both are saved.
3. Try a negative fee, fee 12.345, or slots 1.5 and confirm PHP rejects it.
4. Delete the sample service and confirm the others remain.
