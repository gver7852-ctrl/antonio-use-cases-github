# Vehicle Rental Information System

## Requirements
Local PHP server with PDO MySQL support and a MySQL database.
(XAMPP works. The `mbstring` PHP extension, enabled by default in XAMPP, is also used.)

## Database
Database name: `vehicle_rental_db`

Main table: `rentals`

| Column | Meaning |
| --- | --- |
| `id` | Generated by MySQL |
| `customer_name` | Customer Name |
| `vehicle_plate` | Vehicle Plate Number |
| `rental_start` | Rental Start Date |
| `return_date` | Return Date |

## Setup
1. Place the `vehicle-rental-system` folder in the local web server's document root (XAMPP: `htdocs`).
2. Import `database.sql` (phpMyAdmin > Import). It creates the database, the table, and 4 fictional records. Import it into a fresh setup only once.
3. Set local credentials and the database name in `config.php`.
4. Open the local URL below.

## Local URL
http://localhost/vehicle-rental-system/index.php

## Features
Create, list, view, edit, delete, and case-specific validation.

**Case rule:** All fields are required. Dates must be real calendar dates in YYYY-MM-DD format. The return date must be later than the rental start date.

## Files
| File | Role |
| --- | --- |
| `config.php` | Database settings and the PDO connection `$pdo` |
| `index.php` | Lists records with Add New, View, Edit, Delete links |
| `create.php` | Form, PHP validation, prepared INSERT |
| `view.php` | All fields of one record |
| `edit.php` | Filled form, validation, prepared UPDATE for one ID |
| `delete.php` | Confirmation page; deletes only on POST |
| `database.sql` | Database, table, sample records |
| `README.md` | This guide |

## Check the solution
1. Create Avery Tan / ABC-1234 / 2026-11-10 / 2026-11-12 and confirm the details.
2. Change the plate to DEF-5678 and confirm the same rental is updated.
3. Try a return date equal to or earlier than the start, or an invalid date, and confirm PHP rejects it.
4. Cancel on the delete page and confirm the rental remains; then confirm deletion.
