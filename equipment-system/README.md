# Equipment Information System

## Requirements
Local PHP server with PDO MySQL support and a MySQL database.
(XAMPP works. The `mbstring` PHP extension, enabled by default in XAMPP, is also used.)

## Database
Database name: `equipment_db`

Main table: `equipment`

| Column | Meaning |
| --- | --- |
| `id` | Generated by MySQL |
| `equipment_name` | Equipment Name |
| `brand` | Brand |
| `storage_location` | Storage Location |
| `quantity` | Quantity |

## Setup
1. Place the `equipment-system` folder in the local web server's document root (XAMPP: `htdocs`).
2. Import `database.sql` (phpMyAdmin > Import). It creates the database, the table, and 4 fictional records. Import it into a fresh setup only once.
3. Set local credentials and the database name in `config.php`.
4. Open the local URL below.

## Local URL
http://localhost/equipment-system/index.php

## Features
Create, list, view, edit, delete, and case-specific validation.

**Case rule:** All fields are required. Quantity must be a whole number greater than or equal to zero; zero is valid.

## Files
| File | Role |
| --- | --- |
| `config.php` | Database settings and the PDO connection `$pdo` |
| `index.php` | Lists records with Add New, View, Edit, Delete links |
| `create.php` | Form, PHP validation, prepared INSERT |
| `view.php` | All fields of one record |
| `edit.php` | Filled form, validation, prepared UPDATE for one ID |
| `delete.php` | Confirmation page; deletes only on POST |
| `database.sql` | Database, table, sample records |
| `README.md` | This guide |

## Check the solution
1. Create Digital Multimeter / TestLab / Laboratory 2 / 3 and confirm it appears in the list and detail page.
2. Change quantity from 3 to 0 and confirm it is saved under the same ID.
3. Submit -1 or 1.5 for quantity and confirm PHP rejects it without saving.
4. Delete the sample entry after confirmation and confirm it is removed.
